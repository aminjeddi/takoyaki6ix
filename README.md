# Takoyaki6ix

Single-page landing site for Takoyaki6ix — Kensington Market's tiny takoyaki + bao spot.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Sections
- Hero
- Marquee
- About
- Menu (Takoyaki / Baos / Onigiri & Sides / Drinks)
- Reviews (pulled from real Google reviews)
- Visit (address, hours, order links)
- Footer

Edit menu items in `components/Menu.tsx`, address/hours in `components/Visit.tsx`.
